# RenKairo Blog-Installer ⛩️

> **Production-Ready Technical Blog & Installer Hub for RenKairo IDE v1.0.0**

This repository contains the production website showcasing RenKairo's AI-powered cloud orchestration architecture alongside the official `RenKairo IDE Setup 1.0.0.exe` setup binary replicated from the core `renkairo/Rekairo-ui` build outputs.

---

## 🌟 Key Features

- 📖 **Deep Technical Blog Articles**: 4 comprehensive architectural deep dives covering Intent DAG resolution, Electron 44 + Monaco + xterm.js PTY multiplexing, SSH node federation, and disposable Colab GPU orchestration.
- 💾 **Replicated Setup Binary**: Direct download host for `RenKairo IDE Setup 1.0.0.exe` (~122 MB) with SHA-256 hash validation and system specs.
- ⚡ **Natural Language Intent Simulator**: Live interactive sandbox demonstrating how plain English prompts are parsed into multi-node execution steps.
- 📐 **Interactive Topology Inspector**: Visual system map of Client Layer -> Spring Cloud API Gateway -> Spring Boot 3 Shiro Backend -> FastAPI Node Agents -> Compute Layer.
- 🚀 **Production Deployment Ready**: Ships with Vite 6 bundle optimization, Tailwind CSS, Dockerfile, Nginx config, and Vercel/Netlify deployment guides.

---

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript, Vite 6
- **Styling**: Tailwind CSS v4, Glassmorphism, Dark Aesthetics
- **Icons**: Lucide Icons
- **Deployment**: Docker, Nginx, Vercel, Netlify

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle (tsc + vite build)
npm run build

# Preview production build locally
npm run preview
```
